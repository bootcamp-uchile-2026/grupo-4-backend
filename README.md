## Description

**LaSobremesa** es un ecommerce orientado a la comercialización de productos artesanales provenientes de proveedores locales.

El backend expone una API REST organizada en distintos dominios de negocio, incluyendo catálogo, usuarios y proveedores, carrito y pedidos, checkout, autenticación y cuenta, comunidad y fidelización, y logística.


## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```
